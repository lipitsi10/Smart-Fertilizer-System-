# Smart-Fertilizer-System-
Smart Fertilizer System -Robo Rumble Technomania

## 1. Project Overview

Smart Fertilizer system is a device that tests the soil, check and analysis soil condition. Then it gives recommended fertilizer to be used and crops you can plant and it Uses real-time soil monitoring. Automatically dispenses fertilizer when needed.Reduces human error and guesswork

## 2. Problem Statement

Most famers in South Africa face problems such as: 
.poor plant growth 
.uneven nutrient distribution 
.fertilizer waste
.high labor costs, and environmental 

## 3. Proposed Solution
The smart fertilizer system:

Reads the soil condition
Test the soil.
Analysis and give recommended fertilizers and crops.
Monitor temperature in Greenhouse.


## 4. How It Works

The system collect soil data and analysis it then give results by giving recommended crops and fertillizer
